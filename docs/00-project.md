# Паспорт проекта Pulse Search

## 1. Название
**Pulse Search** — поисковая система с поддержкой семантического поиска и векторизации документов.

## 2. Происхождение
**Собственный проект**. Исходный код разработан автором в рамках изучения ML и веб-разработки.

## 3. Назначение и решаемая проблема
Проект решает проблему поиска по индексированным сайтам с учетом не только ключевых слов, но и смысла запроса. 
Используется гибридный подход: TF-IDF для быстрого поиска по словам и SBERT (Sentence Transformers) для семантического ранжирования. 
Поддерживаются русский и английский языки.

## 4. Целевые пользователи и их роли
- **Администратор:** добавляет сайты на индексацию через админ-панель, следит за статусом обработки, запускает переиндексацию.
- **Пользователь (гость):** вводит поисковые запросы, просматривает результаты, переходит по ссылкам, запрашивает похожие страницы.

## 5. Три основные функции
1. **Индексация сайтов:** сканирование до 10 страниц с одного сайта, извлечение текста, токенизация (spaCy + pymorphy3), построение инвертированного индекса.
2. **Гибридный поиск:** комбинация TF-IDF и SBERT для точного ранжирования результатов.
3. **Поиск похожих страниц:** рекомендации на основе семантической близости эмбеддингов.

## 6. Технологический стек
- **Backend:** Python 3.10, FastAPI, SQLAlchemy, Celery, Redis, PostgreSQL + pgvector.
- **ML:** Sentence Transformers (SBERT), spaCy, pymorphy3, NumPy, SciPy, scikit-learn.
- **Frontend:** React 18, Vite, TailwindCSS 4, React Router, Axios, Nginx.
- **Инфраструктура:** Docker, Docker Compose.

## 9. Журнал запуска (проблемы и решения)
В процессе запуска проекта возникли следующие проблемы:

| Проблема | Решение |
|----------|---------|
| `kombu.exceptions.VersionMismatch: Redis transport requires redis-py versions 6.1.0 or later` | Обновлена версия `redis` в `requirements.txt` до `>=6.1.0`. |
| Отсутствие `scikit-learn` в `requirements.txt` (ошибка `ModuleNotFoundError: No module named 'sklearn'` при поиске) | Добавлен `scikit-learn==1.3.2` в `requirements.txt`. |
| Nginx требует `.htpasswd`, но файла нет — сборка фронтенда падает | Создан файл `frontend/.htpasswd` с хэшем пароля (bcrypt). |
| После индексации поиск не работает, пока не вызовешь `/api/reindex` | Это особенность архитектуры (эмбеддинги считаются отложенно). В README добавлен шаг с ручным запуском `reindex`. |
